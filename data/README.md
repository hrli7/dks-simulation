# Data directory

All generated content and private inputs live here and are ignored by Git.
Only this directory guide is versioned. Do not force-add generated data.

- `private/retailer_evidence.json`: your sourced retailer facts for Luna.
- `private/offers.jsonl`: your licensed/authorized normalized merchandise observations.
- `generated/`: Luna-generated option bank, retailer profiles, generation manifest and API cache.
- `catalog.sqlite`: normalized scenario snapshot built by `catalog_io.py`.
- `runs/<run-id>/`: frozen cohort, source snapshots, experiment design, offer lookup,
  prepared sessions, Jev caches, action traces, analysis and errors.
- `demo-inputs/`, `demo-offers.jsonl`, `demo.sqlite`: mechanical fixtures generated by scripts.

Keep snapshots and API caches in access-controlled storage to replay a run exactly.
Never put API keys in this directory or in evidence text. Supply credentials through
process environment variables or a secret manager.
